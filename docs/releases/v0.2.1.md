给常用麦克风排好顺序，连接变化时自动接替。

## ⚠️ 注意事项

这是首次公开版，尚未完成 Apple 公证。解压后将应用移到“应用程序”；首次打开若被系统阻止，请确认下载来源可信，再到“系统设置 → 隐私与安全性”中选择“仍要打开”。

首次启动默认暂停自动切换。请先加入常用麦克风，将内置麦克风放在末尾，再开启自动切换。会议与录音软件请选择“系统默认输入”。安装包同时支持两类 Mac 芯片，Intel Mac 尚未实机验证。

## 🎉 新功能

- 在菜单栏保存麦克风优先级，当前输入不可用时自动选择下一支，恢复稳定后切回。
- 支持 DJI Mic Mini 2 发射器未连接时接替，以及小米遥控器断联时跳过 MiRemoteV 输入。
- 临时使用其他麦克风 30 分钟；点击最高可用优先级即可继续自动管理。

## ✨ 改进

- 拖动时腾出落点空位；只有当前输入显示带青绿底色的勾。
- 专属 P 麦克风图标用于菜单栏、使用说明与“关于”；“关于”可打开项目主页。

## 🐛 问题修复

- DJI 接收器仍插着但发射器已关闭时，不再仅凭接收器在线状态选中它。
- 小米遥控器已断联但虚拟输入仍留在系统列表时，自动跳过该输入。

## English

Rank your microphones and let another input take over when a connection changes.

## ⚠️ Heads-up

This first public release is not notarized by Apple. Extract it and move the app to Applications. If macOS blocks the first launch, verify the download source, then use System Settings → Privacy & Security → Open Anyway.

Automatic switching starts paused. Add your microphones, put the built-in input last, and enable it. Meeting and recording apps should use System Default. Both Mac chip types are included; physical Intel Mac testing is still pending.

## 🎉 New features

- Save microphone priorities in the menu bar, switch when an input becomes unavailable, and return after stable recovery.
- Handle unlinked DJI Mic Mini 2 transmitters and disconnected Xiaomi remotes using MiRemoteV.
- Use another input for 30 minutes; select the highest available priority to continue automatic routing.

## ✨ Improvements

- Drag rows into an open gap. Only the current input has a tinted checkmark.
- Dedicated P microphone icons appear in the menu bar, Help and About. About links to the project.

## 🐛 Bug fixes

- A plugged-in DJI receiver no longer counts as usable solely because it remains online after its transmitter shuts down.
- MiRemoteV is skipped when the Xiaomi remote disconnects, even though the virtual input remains listed.
