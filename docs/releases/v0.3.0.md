## English

Get new versions from the menu bar while keeping your microphone setup.

## ⚠️ Heads-up

To focus testing and maintenance on the platform in use, this release supports Apple Silicon Macs only. macOS 13 or later is still required. Download the Apple Silicon package.

v0.2.1 has no update menu, so install this version manually once. Future upgrades are available under “更多 → 检查更新”. The app is still not notarized by Apple. If the first launch is blocked, verify the download source, then choose Open Anyway in System Settings → Privacy & Security.

## 🎉 New features

- Check the latest stable GitHub release from the menu bar, read its notes or download it.
- Install and restart after downloading, preserving microphone priorities and settings.
- Cancel a download or installation preparation. If the app’s location cannot be updated, get an explanation and a link for manual installation.

## ✨ Improvements

- Downloads, app identity and version are checked before installation. Invalid updates keep the current app; replacement or startup failures attempt to restore the previous version.
- Both READMEs now link to SayAll and explain how a Xiaomi remote becomes a microphone, and why its virtual input can remain listed after Bluetooth disconnection.
