The accepted design is a compact native macOS utility in Operate mode. A single approximately 340-point menu bar panel uses system fonts, SF Symbols, native controls, and automatic light/dark appearance. The menu bar shows a monochrome microphone symbol, with distinct pause, temporary-use, and error states. The panel contains the actual system input and latest reason, ordered saved devices including offline entries, other discovered inputs with explicit add actions, a login toggle, and a small overflow menu. Priority numbers and the actual-input checkmark have separate meanings. All interface copy is Chinese. There is no primary window, dashboard, recording meter, or decorative branding.
